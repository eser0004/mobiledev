🧠 KORT FORKLARING (overblik)

Appen er en React Native funktionel komponent, der viser:

    - et logo

    - firmanavn + beskrivelse

    - kontaktinfo

    - adresse
    → alt samlet i et kort (business card layout).

React Native bruger:

    - View = container (som <div> i web)

    - Text = tekst

    - Image = billede

    - StyleSheet = styling (som CSS, men i JS)

-------------------------------------------------------------------------------------------------------------------------
🧩 KODEN – DEL FOR DEL (kort og klart)
1️⃣ Imports 

    import { StatusBar } from "expo-status-bar";
    impor { StyleSheet, Text, View, Image } from "react-native";
    
Hvad det gør:

- Importerer de komponenter vi bruger

- StatusBar styrer statusbaren på telefonen

- View, Text, Image er byggestenene i UI
